# HiBlue – update0.0.8

**THE JUDGMENT** — primul joc nativ HiBlue: horror psihologic first-person în Kotlin, grafică 3D realistă cu Google Filament.
Se pornește din HiBlue → Games → The Judgment (se joacă pe orizontală). Raport tehnic complet: `docs/JUDGMENT_PROTOTYPE.md`.

Arhitectura rămâne cea din 0.0.6/0.0.7 (Android Host + NativeBridge + Game Platform); jocul este un joc `native-kotlin`
înregistrat în `NativeGames.registerBuiltIn()` și în `assets/games/catalog.js`.

## Aplicare
`update0.0.6.txt`, `update0.0.7.txt`, `update0.0.8.txt` în rădăcina repo-ului (sau în `updates/`), lângă `hiblue.txt`. `build.yml` nu se modifică.
Opțional în Supabase: `supabase/update0.0.8.sql` (doar pentru ratinguri).

## Noutăți tehnice
- Dependențe noi: `filament-android` și `gltfio-android` 1.51.0 (Maven Central). Build limitat la `arm64-v8a`.
- Activity nou `.judgment.JudgmentActivity` (orizontal), `uses-feature` OpenGL ES 3.0.
- `registry.registerPresentation` (copertă pentru jocuri native); player-ul web se închide singur la ieșirea din jocul nativ.

## Verificat / neverificat
Vezi secțiunea 8 din `docs/JUDGMENT_PROTOTYPE.md`: logica a fost verificată în Node; **compilarea, aspectul și performanța pe telefon NU au fost verificate**.

/* =====================================================================
   HiBlue · Game Platform · Game Registry
   Leagă un id din catalog de implementarea lui în runtime-ul Web:
     factory(host, api) -> { restart?(), pause?(), resume?(), destroy() }
     presentation: { cover(k) -> șir SVG }
   Jocurile native nu se înregistrează aici: sunt înregistrate în host (NativeGames.kt).
   ===================================================================== */
(function (root) {
  "use strict";
  var GP = root.GamePlatform;
  var web = {};
  var pres = {};
  GP.registry = {
    registerWeb: function (id, factory, presentation) {
      if (!GP.is.id(id)) throw GP.err("BAD_PARAMS", "id de joc invalid");
      if (typeof factory !== "function") throw GP.err("BAD_PARAMS", "factory trebuie să fie funcție");
      var p = presentation || {};
      web[id] = { factory: factory, presentation: { cover: typeof p.cover === "function" ? p.cover : null } };
      return true;
    },
    /* Copertă / prezentare pentru jocuri care nu au implementare web (ex. native). */
    registerPresentation: function (id, p) {
      if (!GP.is.id(id)) throw GP.err("BAD_PARAMS", "id de joc invalid");
      pres[id] = { cover: p && typeof p.cover === "function" ? p.cover : null };
      return true;
    },
    presentation: function (id) {
      var w = web[id];
      if (w && w.presentation.cover) return w.presentation;
      return pres[id] || null;
    },
    getWeb: function (id) { return web[id] || null; },
    has: function (id) { return !!web[id]; },
    unregister: function (id) { delete web[id]; },
    _reset: function () { web = {}; pres = {}; }
  };
})(typeof window !== "undefined" ? window : globalThis);

package ro.lingurar.hiblue.judgment.audio

import android.content.Context
import android.media.AudioAttributes
import android.media.AudioFocusRequest
import android.media.AudioFormat
import android.media.AudioManager
import android.media.AudioTrack
import android.os.Build
import kotlin.math.abs
import kotlin.math.cos
import kotlin.math.max
import kotlin.math.min
import kotlin.math.sin
import kotlin.math.sqrt

enum class Sfx { CREAK, CLICK, STEP1, STEP2, THUD }

/**
 * Sunet pentru joc: AudioTrack static (fără fișiere), panoramare stereo + atenuare cu distanța față de ascultător
 * (poziționare simplă, nu HRTF). Gestionează focusul audio: pe pierdere de focus pune ambientul pe pauză.
 */
class AudioEngine(ctx: Context, private val bank: SoundBank) {
    private val am = ctx.getSystemService(Context.AUDIO_SERVICE) as AudioManager
    private val attrs = AudioAttributes.Builder()
        .setUsage(AudioAttributes.USAGE_GAME)
        .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
        .build()
    private var ambient: AudioTrack? = null
    private val sfx = HashMap<Sfx, AudioTrack>()
    private var focusRequest: AudioFocusRequest? = null
    private var hasFocus = false
    private var started = false
    @Volatile private var released = false

    private val focusListener = AudioManager.OnAudioFocusChangeListener { change ->
        when (change) {
            AudioManager.AUDIOFOCUS_GAIN -> { hasFocus = true; if (started) ambient?.setVolume(0.6f) ; resumeAmbient() }
            AudioManager.AUDIOFOCUS_LOSS, AudioManager.AUDIOFOCUS_LOSS_TRANSIENT -> { hasFocus = false; pauseAmbient() }
            AudioManager.AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK -> { ambient?.setVolume(0.2f) }
        }
    }

    private fun makeTrack(data: ShortArray, loop: Boolean): AudioTrack {
        val fmt = AudioFormat.Builder()
            .setSampleRate(SoundSynth.RATE)
            .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
            .setChannelMask(AudioFormat.CHANNEL_OUT_MONO)
            .build()
        val t = AudioTrack.Builder()
            .setAudioAttributes(attrs)
            .setAudioFormat(fmt)
            .setBufferSizeInBytes(data.size * 2)
            .setTransferMode(AudioTrack.MODE_STATIC)
            .build()
        t.write(data, 0, data.size)
        if (loop) t.setLoopPoints(0, data.size, -1)
        return t
    }

    @Suppress("DEPRECATION")
    private fun requestFocus(): Boolean {
        val r: Int
        if (Build.VERSION.SDK_INT >= 26) {
            val fr = AudioFocusRequest.Builder(AudioManager.AUDIOFOCUS_GAIN)
                .setAudioAttributes(attrs)
                .setOnAudioFocusChangeListener(focusListener)
                .build()
            focusRequest = fr
            r = am.requestAudioFocus(fr)
        } else {
            r = am.requestAudioFocus(focusListener, AudioManager.STREAM_MUSIC, AudioManager.AUDIOFOCUS_GAIN)
        }
        return r == AudioManager.AUDIOFOCUS_REQUEST_GRANTED
    }

    @Suppress("DEPRECATION")
    private fun abandonFocus() {
        if (Build.VERSION.SDK_INT >= 26) {
            focusRequest?.let { am.abandonAudioFocusRequest(it) }
        } else {
            am.abandonAudioFocus(focusListener)
        }
        hasFocus = false
    }

    fun start() {
        if (released || started) return
        hasFocus = requestFocus()
        ambient = makeTrack(bank.ambient, true).also { it.setVolume(0.6f) }
        sfx[Sfx.CREAK] = makeTrack(bank.creak, false)
        sfx[Sfx.CLICK] = makeTrack(bank.click, false)
        sfx[Sfx.STEP1] = makeTrack(bank.step1, false)
        sfx[Sfx.STEP2] = makeTrack(bank.step2, false)
        sfx[Sfx.THUD] = makeTrack(bank.thud, false)
        started = true
        if (hasFocus) ambient?.play()
    }

    private fun resumeAmbient() { try { if (started && hasFocus) ambient?.play() } catch (e: Exception) {} }
    private fun pauseAmbient() { try { ambient?.pause() } catch (e: Exception) {} }

    fun pause() { pauseAmbient(); abandonFocus() }
    fun resume() { if (released || !started) return; hasFocus = requestFocus(); resumeAmbient() }

    /**
     * Redă un efect. dx/dz = vectorul de la ascultător la sursă; yaw = orientarea ascultătorului.
     * Pentru sunete "în cap" (pași, click) folosește play(sfx, volum) fără poziție.
     */
    fun play(s: Sfx, volume: Float) = playStereo(s, volume, volume)

    fun playAt(s: Sfx, dx: Float, dz: Float, yaw: Float, gain: Float) {
        val dist = sqrt(dx * dx + dz * dz)
        val att = 1f / (1f + 0.45f * dist * dist)
        // unghiul sursei în sistemul ascultătorului: dreapta = (cos yaw, -sin yaw)
        val rx = cos(yaw); val rz = -sin(yaw)
        val side = if (dist < 1e-4f) 0f else max(-1f, min(1f, (dx * rx + dz * rz) / dist))
        val l = gain * att * sqrt((1f - side) * 0.5f + 0.15f)
        val r = gain * att * sqrt((1f + side) * 0.5f + 0.15f)
        playStereo(s, min(1f, l), min(1f, r))
    }

    @Suppress("DEPRECATION")
    private fun playStereo(s: Sfx, l: Float, r: Float) {
        if (released || !started || !hasFocus) return
        val t = sfx[s] ?: return
        try {
            t.stop()
            t.setPlaybackHeadPosition(0)
            t.setStereoVolume(l, r)
            t.play()
        } catch (e: Exception) {
        }
    }

    fun release() {
        released = true
        try { ambient?.release() } catch (e: Exception) {}
        for (t in sfx.values) try { t.release() } catch (e: Exception) {}
        sfx.clear()
        abandonFocus()
    }
}

package ro.lingurar.hiblue.judgment.audio

import java.util.Random
import kotlin.math.PI
import kotlin.math.exp
import kotlin.math.max
import kotlin.math.min
import kotlin.math.sin

/** Bufere PCM 16 biți mono, 22050 Hz, generate din cod (nu există fișiere audio în repo). */
class SoundBank(
    val ambient: ShortArray, val creak: ShortArray, val click: ShortArray,
    val step1: ShortArray, val step2: ShortArray, val thud: ShortArray
)

object SoundSynth {
    const val RATE = 22050

    private fun toPcm(f: FloatArray, gain: Float): ShortArray {
        var peak = 1e-6f
        for (v in f) peak = max(peak, Math.abs(v))
        val k = gain / peak
        return ShortArray(f.size) { i -> (max(-1f, min(1f, f[i] * k)) * 32767f).toInt().toShort() }
    }

    /** Filtru trece-jos cu un pol, aplicat circular (bucla rămâne fără cusătură). */
    private fun lowpassCircular(x: FloatArray, a: Float) {
        var y = x[x.size - 1]
        for (pass in 0 until 2) for (i in x.indices) { y += a * (x[i] - y); x[i] = y }
    }

    /** 8 secunde în buclă: zumzet 55 / 82.5 Hz, vânt filtrat, puls lent. Frecvențele sunt multipli de 1/8 Hz => ciclu întreg. */
    fun ambient(): ShortArray {
        val n = RATE * 8
        val rnd = Random(11)
        val noise = FloatArray(n) { rnd.nextFloat() * 2f - 1f }
        lowpassCircular(noise, 0.02f)
        val out = FloatArray(n)
        for (i in 0 until n) {
            val t = i.toFloat() / RATE
            val hum = 0.55f * sin(2f * PI.toFloat() * 55f * t) + 0.3f * sin(2f * PI.toFloat() * 82.5f * t + 0.7f)
            val pulse = 0.75f + 0.25f * sin(2f * PI.toFloat() * 0.25f * t)
            out[i] = (hum * pulse + noise[i] * 9f)
        }
        return toPcm(out, 0.55f)
    }

    /** Scârțâit de ușă: dinte de ferăstrău cu frecvență glisantă + vibrato + zgomot. */
    fun creak(): ShortArray {
        val n = (RATE * 1.5f).toInt()
        val rnd = Random(5)
        val out = FloatArray(n)
        var phase = 0f
        for (i in 0 until n) {
            val t = i.toFloat() / RATE
            val p = t / 1.5f
            val f = 150f + 170f * p + 25f * sin(2f * PI.toFloat() * 7f * t) + 40f * sin(2f * PI.toFloat() * 2.3f * t)
            phase += f / RATE
            val saw = (phase - Math.floor(phase.toDouble()).toFloat()) * 2f - 1f
            val env = min(1f, t * 12f) * exp(-max(0f, p - 0.7f) * 8f) * (0.6f + 0.4f * sin(2f * PI.toFloat() * 3.1f * t + 1f))
            out[i] = (saw * 0.6f + (rnd.nextFloat() * 2f - 1f) * 0.25f) * env
        }
        return toPcm(out, 0.7f)
    }

    fun click(): ShortArray {
        val n = (RATE * 0.06f).toInt()
        val rnd = Random(3)
        val out = FloatArray(n) { i -> (rnd.nextFloat() * 2f - 1f) * exp(-i / (RATE * 0.006f)) + 0.6f * sin(2f * PI.toFloat() * 900f * i / RATE) * exp(-i / (RATE * 0.01f)) }
        return toPcm(out, 0.6f)
    }

    private fun step(seed: Int, f0: Float): ShortArray {
        val n = (RATE * 0.22f).toInt()
        val rnd = Random(seed.toLong())
        var lp = 0f
        val out = FloatArray(n)
        for (i in 0 until n) {
            lp += 0.12f * ((rnd.nextFloat() * 2f - 1f) - lp)
            val env = exp(-i / (RATE * 0.045f))
            out[i] = (lp * 1.5f + sin(2f * PI.toFloat() * f0 * i / RATE) * 0.8f) * env
        }
        return toPcm(out, 0.5f)
    }

    fun step1() = step(21, 70f)
    fun step2() = step(22, 62f)

    /** Pocnet surd (ușa ajunge la capăt). */
    fun thud(): ShortArray {
        val n = (RATE * 0.4f).toInt()
        val rnd = Random(9)
        var lp = 0f
        val out = FloatArray(n)
        for (i in 0 until n) {
            lp += 0.05f * ((rnd.nextFloat() * 2f - 1f) - lp)
            out[i] = (lp * 3f + sin(2f * PI.toFloat() * 48f * i / RATE)) * exp(-i / (RATE * 0.09f))
        }
        return toPcm(out, 0.8f)
    }

    fun generate() = SoundBank(ambient(), creak(), click(), step1(), step2(), thud())
}

package ro.lingurar.hiblue.judgment.game

import kotlin.math.max
import kotlin.math.min

/** Cutie aliniată pe axe (metri, spațiu lume: +Y sus, camera privește spre -Z la yaw 0). */
class Aabb(
    val minX: Float, val minY: Float, val minZ: Float,
    val maxX: Float, val maxY: Float, val maxZ: Float,
    val name: String = ""
) {
    /** Cutiile dezactivate (ex. ușa deschisă) sunt ignorate de fizică și de raze. */
    @Volatile var enabled: Boolean = true
}

object Collision {
    /**
     * Rază vs cutie (metoda "slab"). Întoarce distanța t >= 0 până la prima intersecție
     * sau -1f dacă nu lovește în maxDist. Direcția trebuie să fie normalizată.
     */
    fun raycast(
        ox: Float, oy: Float, oz: Float,
        dx: Float, dy: Float, dz: Float,
        maxDist: Float, b: Aabb
    ): Float {
        var tMin = 0f
        var tMax = maxDist
        val o = floatArrayOf(ox, oy, oz)
        val d = floatArrayOf(dx, dy, dz)
        val lo = floatArrayOf(b.minX, b.minY, b.minZ)
        val hi = floatArrayOf(b.maxX, b.maxY, b.maxZ)
        for (i in 0..2) {
            if (Math.abs(d[i]) < 1e-8f) {
                if (o[i] < lo[i] || o[i] > hi[i]) return -1f
            } else {
                val inv = 1f / d[i]
                var t1 = (lo[i] - o[i]) * inv
                var t2 = (hi[i] - o[i]) * inv
                if (t1 > t2) { val s = t1; t1 = t2; t2 = s }
                tMin = max(tMin, t1)
                tMax = min(tMax, t2)
                if (tMin > tMax) return -1f
            }
        }
        return tMin
    }

    /** Cea mai apropiată lovitură dintre toate cutiile active, sau -1f. */
    fun nearest(
        ox: Float, oy: Float, oz: Float,
        dx: Float, dy: Float, dz: Float,
        maxDist: Float, boxes: List<Aabb>
    ): Float {
        var best = -1f
        for (b in boxes) {
            if (!b.enabled) continue
            val t = raycast(ox, oy, oz, dx, dy, dz, maxDist, b)
            if (t >= 0f && (best < 0f || t < best)) best = t
        }
        return best
    }
}

package ro.lingurar.hiblue.judgment.game

import ro.lingurar.hiblue.judgment.world.LevelSpec
import kotlin.math.cos
import kotlin.math.sin

/** Ușa interactivă: mașină de stări CLOSED -> OPENING -> OPEN -> CLOSING, cu coliziune activă doar cât e (aproape) închisă. */
class DoorController(private val collider: Aabb) {
    enum class State { CLOSED, OPENING, OPEN, CLOSING }

    companion object {
        const val SPEED_DEG_PER_SEC = 75f
        /** Sub acest unghi ușa încă blochează trecerea. */
        const val BLOCK_BELOW_DEG = 20f
    }

    var state = State.CLOSED
        private set
    /** Unghi liniar 0..DOOR_OPEN_DEG (fără easing). */
    var angle = 0f
        private set

    val isOpenOrOpening: Boolean get() = state == State.OPEN || state == State.OPENING

    /** Cere comutarea. Întoarce true dacă acum se deschide, false dacă se închide. */
    fun toggle(): Boolean {
        return if (isOpenOrOpening) {
            state = State.CLOSING; false
        } else {
            state = State.OPENING; true
        }
    }

    /** Restaurare din salvare (fără animație). */
    fun setOpen(open: Boolean) {
        angle = if (open) LevelSpec.DOOR_OPEN_DEG else 0f
        state = if (open) State.OPEN else State.CLOSED
        collider.enabled = angle < BLOCK_BELOW_DEG
    }

    /** Întoarce true dacă unghiul s-a schimbat (matricea trebuie retrimisă către randare). */
    fun update(dt: Float): Boolean {
        val before = angle
        when (state) {
            State.OPENING -> {
                angle += SPEED_DEG_PER_SEC * dt
                if (angle >= LevelSpec.DOOR_OPEN_DEG) { angle = LevelSpec.DOOR_OPEN_DEG; state = State.OPEN }
            }
            State.CLOSING -> {
                angle -= SPEED_DEG_PER_SEC * dt
                if (angle <= 0f) { angle = 0f; state = State.CLOSED }
            }
            else -> {}
        }
        collider.enabled = angle < BLOCK_BELOW_DEG
        return angle != before
    }

    /** Unghiul vizual cu easing (start/oprire line). */
    fun easedAngleDeg(): Float {
        val p = angle / LevelSpec.DOOR_OPEN_DEG
        return LevelSpec.DOOR_OPEN_DEG * (p * p * (3f - 2f * p))
    }

    /**
     * Matrice 4x4 coloană-major (format Filament): translație la balama * rotație Y(-unghi).
     * Unghi negativ => ușa se deschide spre interiorul camerei (+Z).
     */
    fun matrix(): FloatArray {
        val a = Math.toRadians(-easedAngleDeg().toDouble())
        val c = cos(a).toFloat()
        val s = sin(a).toFloat()
        return floatArrayOf(
            c, 0f, -s, 0f,
            0f, 1f, 0f, 0f,
            s, 0f, c, 0f,
            LevelSpec.DOOR_HINGE_X, 0f, LevelSpec.DOOR_HINGE_Z, 1f
        )
    }
}

/** Starea serializabilă a jocului (salvare). */
class SaveData(

/** Logica jocului: jucător, ușă, lanternă, pâlpâirea becului, țintirea obiectelor. Pură Kotlin, testabilă pe JVM. */
class GameWorld(private val events: GameEvents) {
    val colliders: List<Aabb> = LevelSpec.colliders()
    val player = PlayerController(colliders)
    val door = DoorController(LevelSpec.doorCollider)

    var flashlightOn = true
        private set
    var playSeconds = 0f
        private set

    /** Textul pentru butonul "Interacționează", sau null dacă nu ținți nimic. */
    var hint: String? = null
        private set

    /** Direcția lanternei (netezită: întârzie ușor în urma camerei, ca o lanternă în mână). */
    var flX = 0f; var flY = 0f; var flZ = -1f
        private set
    var flPosX = 0f; var flPosY = 0f; var flPosZ = 0f
        private set
    /** Multiplicatori de intensitate 0..1 pentru becul din cameră și lumina din coridor. */
    var bulbFactor = 1f
        private set
    var corridorFactor = 1f
        private set

    private var bob = 0f
    private val rnd = Random(7)
    private var flickerLeft = 0f
    private var nextFlicker = 4f
    private var stepAcc = 0f
    private var leftFoot = true
    private val doorRayBox = Aabb(1.05f, 0f, -2.9f, 1.95f, 2.1f, -2.4f, "door-ray")

    init {
        player.x = LevelSpec.SPAWN_X
        player.z = LevelSpec.SPAWN_Z
        player.yaw = LevelSpec.SPAWN_YAW
        // jucătorul apare puțin deasupra podelei: gravitația îl așază în primul cadru
        player.y = 0.25f
        updateFlashlightPose(1f, true)
    }

    fun camDirX() = -sin(player.yaw) * cos(player.pitch)
    fun camDirY() = sin(player.pitch)
    fun camDirZ() = -cos(player.yaw) * cos(player.pitch)

    /** Poziția ochiului, cu balans la mers. */
    fun eyeX() = player.eyeX()
    fun eyeY() = player.eyeY() + bob
    fun eyeZ() = player.eyeZ()
    fun toggleFlashlight() {
        flashlightOn = !flashlightOn
        events.onFlashlight(flashlightOn)
    }

    fun interact() {
        if (!canInteractDoor()) return
        val opening = door.toggle()
        events.onDoor(opening, 1.5f, 1.0f, LevelSpec.DOOR_HINGE_Z)
    }

    private fun canInteractDoor(): Boolean {
        val ox = player.eyeX(); val oy = player.eyeY(); val oz = player.eyeZ()
        val dx = camDirX(); val dy = camDirY(); val dz = camDirZ()
        val td = Collision.raycast(ox, oy, oz, dx, dy, dz, 2.0f, doorRayBox)
        if (td < 0f) return false
        // ceva solid (alt decât ușa) în față?
        for (b in colliders) {
            if (!b.enabled || b === LevelSpec.doorCollider) continue
            val t = Collision.raycast(ox, oy, oz, dx, dy, dz, td, b)
            if (t >= 0f && t < td - 0.02f) return false
        }
        return true
    }

    /** Un pas de simulare. Întoarce true dacă ușa și-a schimbat unghiul (de retrimis matricea la randare). */
    fun update(dt: Float, strafe: Float, forward: Float, lookYaw: Float, lookPitch: Float): Boolean {
        playSeconds += dt
        player.look(lookYaw, lookPitch)
        val before = player.walked
        player.update(dt, strafe, forward)
        val moved = player.walked - before
        bob = if (moved > 1e-4f && player.onGround) sin(player.walked * 5.4f) * 0.022f else bob * 0.8f
        stepAcc += moved
        if (stepAcc >= 0.78f) {
            stepAcc -= 0.78f
            leftFoot = !leftFoot
            events.onFootstep(leftFoot)
        }
        val doorChanged = door.update(dt)
        updateFlicker(dt)
        updateFlashlightPose(dt, false)
        hint = if (canInteractDoor()) (if (door.isOpenOrOpening) "Închide ușa" else "Deschide ușa") else null
        return doorChanged
    }

    private fun updateFlicker(dt: Float) {
        nextFlicker -= dt
        if (flickerLeft <= 0f && nextFlicker <= 0f) {
            flickerLeft = 0.25f + rnd.nextFloat() * 0.5f
            nextFlicker = 3f + rnd.nextFloat() * 7f
        }
        if (flickerLeft > 0f) {
            flickerLeft -= dt
            bulbFactor = if (rnd.nextFloat() < 0.5f) 0.04f + rnd.nextFloat() * 0.3f else 0.6f + rnd.nextFloat() * 0.4f
        } else {
            bulbFactor = 0.93f + 0.07f * sin(playSeconds * 31f) * sin(playSeconds * 7.3f)
        }
        corridorFactor = 0.7f + 0.3f * sin(playSeconds * 2.1f) * sin(playSeconds * 0.7f + 1f)
    }

    private fun updateFlashlightPose(dt: Float, snap: Boolean) {
        val k = if (snap) 1f else 1f - exp(-14f * dt)
        var nx = flX + (camDirX() - flX) * k
        var ny = flY + (camDirY() - flY) * k
        var nz = flZ + (camDirZ() - flZ) * k
        val l = sqrt(nx * nx + ny * ny + nz * nz)
        if (l > 1e-5f) { nx /= l; ny /= l; nz /= l }
        flX = nx; flY = ny; flZ = nz
        // mâna dreaptă: puțin în dreapta, jos și în față față de ochi
        flPosX = eyeX() + player.rightX() * 0.18f + camDirX() * 0.25f
        flPosY = eyeY() - 0.16f + camDirY() * 0.25f
        flPosZ = eyeZ() + player.rightZ() * 0.18f + camDirZ() * 0.25f
    }

    // ---- salvare ----
    fun toSave() = SaveData(door.isOpenOrOpening, player.x, player.z, player.yaw, flashlightOn, playSeconds)

    fun restore(s: SaveData) {
        door.setOpen(s.doorOpen)
        player.x = s.px; player.z = s.pz; player.yaw = s.yaw
        player.y = 0.25f
        flashlightOn = s.flashlightOn
        playSeconds = s.playSeconds
        updateFlashlightPose(1f, true)
    }
}

package ro.lingurar.hiblue.judgment.game

import kotlin.math.ceil
import kotlin.math.cos
import kotlin.math.max
import kotlin.math.min
import kotlin.math.sin
import kotlin.math.sqrt

/**
 * Jucător first-person: cilindru vertical (rază + înălțime) care se mișcă în planul XZ cu
 * coliziune cerc-vs-cutie (alunecă pe pereți) și are gravitație pe axa Y.
 * Convenție: yaw 0 privește spre -Z; yaw crește când te întorci spre stânga.
 */
class PlayerController(private val solids: List<Aabb>) {
    companion object {
        const val RADIUS = 0.30f
        const val HEIGHT = 1.75f
        const val EYE = 1.60f
        const val STEP = 0.30f          // obstacole mai joase de atât se urcă automat
        const val WALK_SPEED = 2.0f     // m/s
        const val GRAVITY = 9.81f
        const val MAX_SUBSTEP = 0.10f   // sub RADIUS: evită "tunelarea" prin pereți subțiri
    }

    var x = 0f
    var y = 0f          // nivelul tălpilor
    var z = 0f
    var vy = 0f
    var yaw = 0f
    var pitch = 0f
    var onGround = false
        private set

    /** Distanța parcursă pe orizontală (pentru balansul camerei și pași). */
    var walked = 0f
        private set

    fun forwardX() = -sin(yaw)
    fun forwardZ() = -cos(yaw)
    fun rightX() = cos(yaw)
    fun rightZ() = -sin(yaw)

    fun look(dYaw: Float, dPitch: Float) {
        yaw += dYaw
        pitch = max(-1.35f, min(1.35f, pitch + dPitch))
    }

    /** strafe / forward în [-1, 1] (stick virtual). */
    fun update(dt: Float, strafe: Float, forward: Float) {
        var mx = rightX() * strafe + forwardX() * forward
        var mz = rightZ() * strafe + forwardZ() * forward
        val len = sqrt(mx * mx + mz * mz)
        if (len > 1f) { mx /= len; mz /= len }
        val dx = mx * WALK_SPEED * dt
        val dz = mz * WALK_SPEED * dt
        val dist = sqrt(dx * dx + dz * dz)
        val n = max(1, ceil(dist / MAX_SUBSTEP).toInt())
        val sx = dx / n
        val sz = dz / n
        val sdt = dt / n
        for (i in 0 until n) {
            x += sx
            z += sz
            resolveHorizontal()
            stepVertical(sdt)
        }
        walked += dist
    }

    private fun resolveHorizontal() {
        for (pass in 0 until 3) {
            var moved = false
            for (b in solids) {
                if (!b.enabled) continue
                // doar obstacolele care ne ating corpul pe verticală și sunt mai înalte decât un prag de urcare
                if (b.maxY <= y + STEP || b.minY >= y + HEIGHT) continue
                val cx = max(b.minX, min(x, b.maxX))
                val cz = max(b.minZ, min(z, b.maxZ))
                val ddx = x - cx
                val ddz = z - cz
                val d2 = ddx * ddx + ddz * ddz
                if (d2 >= RADIUS * RADIUS) continue
                if (d2 > 1e-8f) {
                    val d = sqrt(d2)
                    val push = (RADIUS - d) / d
                    x += ddx * push
                    z += ddz * push
                } else {
                    // centrul e în interiorul cutiei: ieșim pe cea mai apropiată față
                    val l = x - b.minX
                    val r = b.maxX - x
                    val t = z - b.minZ
                    val bt = b.maxZ - z
                    val m = min(min(l, r), min(t, bt))
                    when (m) {
                        l -> x = b.minX - RADIUS
                        r -> x = b.maxX + RADIUS
                        t -> z = b.minZ - RADIUS
                        else -> z = b.maxZ + RADIUS
                    }
                }
                moved = true
            }
            if (!moved) break
        }
    }

    /** Înălțimea suprafeței pe care stă jucătorul (podea 0 sau vârful unui obiect jos). */
    private fun groundHeight(): Float {
        var g = 0f
        for (b in solids) {
            if (!b.enabled) continue
            if (b.maxY > y + STEP + 1e-4f) continue          // prea înalt: e perete, nu suprafață
            if (b.maxY <= g) continue
            val cx = max(b.minX, min(x, b.maxX))
            val cz = max(b.minZ, min(z, b.maxZ))
            val ddx = x - cx
            val ddz = z - cz
            if (ddx * ddx + ddz * ddz < RADIUS * RADIUS * 0.9f) g = b.maxY
        }
        return g
    }

    private fun stepVertical(dt: Float) {
        val ground = groundHeight()
        vy -= GRAVITY * dt
        val oldHead = y + HEIGHT
        y += vy * dt
        // tavan: cutii deasupra capului
        for (b in solids) {
            if (!b.enabled) continue
            if (b.minY < oldHead - 1e-4f) continue
            val cx = max(b.minX, min(x, b.maxX))
            val cz = max(b.minZ, min(z, b.maxZ))
            val ddx = x - cx
            val ddz = z - cz
            if (ddx * ddx + ddz * ddz < RADIUS * RADIUS && y + HEIGHT > b.minY) {
                y = b.minY - HEIGHT
                if (vy > 0f) vy = 0f
            }
        }
        if (y <= ground) {
            y = ground
            vy = 0f
            onGround = true
        } else {
            onGround = false
        }
    }

    fun eyeX() = x
    fun eyeY() = y + EYE
    fun eyeZ() = z
}

/**

 * butoane Interacționează / Lanternă / Ieșire), țintă, indicii și afișajul de performanță.

 */
class HudView(ctx: Context, private val input: InputState) : View(ctx) {
    companion object {
        const val LOOK_SENSITIVITY = 0.0042f   // radiani / pixel
        const val DEADZONE = 0.12f
    }

    private val d = resources.displayMetrics.density
    private fun dp(v: Float) = v * d

    var hint: String? = null
    var perfText: String = ""
    var showPerf = false
    var loadingText: String? = "Se încarcă…"
    var flashOn = true
    var message: String? = null

    private val joyR get() = dp(62f)
    private var joyId = -1; private var joyOx = 0f; private var joyOy = 0f; private var joyX = 0f; private var joyY = 0f
    private var lookId = -1; private var lookX = 0f; private var lookY = 0f
    private var interactId = -1; private var flashId = -1

    private val paint = Paint(Paint.ANTI_ALIAS_FLAG)
    private val text = Paint(Paint.ANTI_ALIAS_FLAG).apply { color = Color.WHITE; typeface = Typeface.create(Typeface.DEFAULT, Typeface.BOLD) }

    private fun interactCx() = width - dp(70f)
    private fun interactCy() = height - dp(80f)
    private fun flashCx() = width - dp(150f)
    private fun flashCy() = height - dp(52f)
    private val btnR get() = dp(34f)
    private fun inCircle(x: Float, y: Float, cx: Float, cy: Float, r: Float) = hypot(x - cx, y - cy) <= r * 1.25f

    override fun onTouchEvent(e: MotionEvent): Boolean {
        when (e.actionMasked) {
            MotionEvent.ACTION_DOWN, MotionEvent.ACTION_POINTER_DOWN -> {
                val i = e.actionIndex
                down(e.getPointerId(i), e.getX(i), e.getY(i))
            }
            MotionEvent.ACTION_MOVE -> {
                for (i in 0 until e.pointerCount) move(e.getPointerId(i), e.getX(i), e.getY(i))
            }
            MotionEvent.ACTION_UP, MotionEvent.ACTION_POINTER_UP -> up(e.getPointerId(e.actionIndex))
            MotionEvent.ACTION_CANCEL -> { for (i in 0 until e.pointerCount) up(e.getPointerId(i)) }
        }
        return true
    }

    private fun down(id: Int, x: Float, y: Float) {
        if (x < dp(80f) && y < dp(80f)) { input.exitPressed = true; return }
        if (x > width * 0.35f && x < width * 0.65f && y < dp(56f)) { input.perfTogglePressed = true; return }
        if (inCircle(x, y, interactCx(), interactCy(), btnR) && interactId < 0) { interactId = id; input.interactPressed = true; return }
        if (inCircle(x, y, flashCx(), flashCy(), btnR * 0.85f) && flashId < 0) { flashId = id; input.flashPressed = true; return }
        if (x < width * 0.45f && joyId < 0) { joyId = id; joyOx = x; joyOy = y; joyX = x; joyY = y; return }
        if (lookId < 0) { lookId = id; lookX = x; lookY = y }
    }

    private fun move(id: Int, x: Float, y: Float) {
        if (id == joyId) {
            joyX = x; joyY = y
            val dx = (x - joyOx) / joyR
            val dy = (y - joyOy) / joyR
            val m = hypot(dx, dy)
            val k = if (m > 1f) 1f / m else 1f
            var sx = dx * k; var sy = dy * k
            if (hypot(sx, sy) < DEADZONE) { sx = 0f; sy = 0f }
            input.strafe = sx
            input.forward = -sy
        } else if (id == lookId) {
            input.addLook(-(x - lookX) * LOOK_SENSITIVITY, -(y - lookY) * LOOK_SENSITIVITY)
            lookX = x; lookY = y
        }
    }

    private fun up(id: Int) {
        if (id == joyId) { joyId = -1; input.strafe = 0f; input.forward = 0f }
        if (id == lookId) lookId = -1
        if (id == interactId) interactId = -1
        if (id == flashId) flashId = -1
    }

    /** La pierderea focusului (pauză): eliberăm toate degetele ca jucătorul să nu "alerge singur". */
    fun resetTouches() {

        input.strafe = 0f; input.forward = 0f
    }

            paint.color = Color.argb(110, 255, 255, 255)
            val dx = joyX - joyOx; val dy = joyY - joyOy; val m = max(1f, hypot(dx, dy) / joyR)
            c.drawCircle(joyOx + dx / m, joyOy + dy / m, dp(26f), paint)
        } else {
            paint.style = Paint.Style.STROKE; paint.strokeWidth = dp(2f); paint.color = Color.argb(60, 255, 255, 255)
            c.drawCircle(dp(110f), h - dp(100f), joyR, paint)
        }
        // butoane
        drawButton(c, interactCx(), interactCy(), btnR, if (hint != null) "E" else "·", hint != null, interactId >= 0)
        drawButton(c, flashCx(), flashCy(), btnR * 0.85f, "☼", flashOn, flashId >= 0)
        drawButton(c, dp(34f), dp(34f), dp(18f), "✕", false, false)

 * NU măsoară timpul GPU (Filament nu îl expune în versiunea folosită) — vezi docs/JUDGMENT_PROTOTYPE.md.
 */
class PerfMonitor(private val ctx: Context) {
    companion object { const val TAG = "JudgmentPerf"; private const val CAP = 1200 }

    private val frameMs = FloatArray(CAP)
    private val cpuMs = FloatArray(CAP)
    private var count = 0
    private var total = 0L
    private var lastLog = System.nanoTime()
    var startup = LinkedHashMap<String, Long>()

    @Volatile var overlayText: String = ""
        private set

    fun mark(name: String, ms: Long) { startup[name] = ms; Log.i(TAG, "startup $name = $ms ms") }

    fun onFrame(intervalNanos: Long, cpuNanos: Long) {
        val i = (total % CAP).toInt()
        frameMs[i] = intervalNanos / 1e6f
        cpuMs[i] = cpuNanos / 1e6f
        total++
        count = minOf(count + 1, CAP)
        val now = System.nanoTime()
        if (now - lastLog > 5_000_000_000L) {
            lastLog = now
            val s = stats()
            overlayText = String.format(Locale.US, "%.0f FPS  p95 %.1f ms  cpu %.1f ms", s.fps, s.p95, s.cpuAvg)
            Log.i(TAG, summaryLine(s))
        }
    }

    class Stats(val fps: Float, val avg: Float, val p50: Float, val p95: Float, val p99: Float, val max: Float, val jank: Int, val cpuAvg: Float, val frames: Int)

    fun stats(): Stats {
        val n = count
        if (n == 0) return Stats(0f, 0f, 0f, 0f, 0f, 0f, 0, 0f, 0)
        val a = frameMs.copyOf(n); a.sort()
        var sum = 0f; var c = 0f; var jank = 0
        for (i in 0 until n) { sum += frameMs[i]; c += cpuMs[i]; if (frameMs[i] > 25f) jank++ }
        val avg = sum / n
        fun pct(p: Float): Float = a[minOf(n - 1, (p * n).toInt())]
        return Stats(1000f / avg, avg, pct(0.5f), pct(0.95f), pct(0.99f), a[n - 1], jank, c / n, n)
    }

    private fun summaryLine(s: Stats): String {
        val thermal = thermal()
        val nativeMb = Debug.getNativeHeapAllocatedSize() / 1048576
        val javaMb = (Runtime.getRuntime().totalMemory() - Runtime.getRuntime().freeMemory()) / 1048576
        return String.format(Locale.US,
            "fps=%.1f avg=%.2fms p50=%.2f p95=%.2f p99=%.2f max=%.2f jank(>25ms)=%d cpu=%.2fms frames=%d nativeHeap=%dMB javaHeap=%dMB thermal=%s",
            s.fps, s.avg, s.p50, s.p95, s.p99, s.max, s.jank, s.cpuAvg, s.frames, nativeMb, javaMb, thermal)
    }

    private fun thermal(): String {
        if (Build.VERSION.SDK_INT < 29) return "n/a"
        return try { (ctx.getSystemService(Context.POWER_SERVICE) as PowerManager).currentThermalStatus.toString() } catch (e: Exception) { "n/a" }
    }

    fun device(): String = Build.MANUFACTURER + " " + Build.MODEL + " (SDK " + Build.VERSION.SDK_INT + ", " + Build.SUPPORTED_ABIS.joinToString(",") + ")"

    /** Raport final (JSON scris manual: fără dependențe). Întoarce calea fișierului sau null. */
    fun writeReport(extra: Map<String, String>): String? {
        return try {
            val s = stats()
            val b = StringBuilder("{\n")
            b.append("  \"device\": \"").append(device().replace("\"", "'")).append("\",\n")
            for ((k, v) in extra) b.append("  \"").append(k).append("\": \"").append(v.replace("\"", "'")).append("\",\n")
            for ((k, v) in startup) b.append("  \"startup_").append(k).append("_ms\": ").append(v).append(",\n")
            b.append(String.format(Locale.US,
                "  \"fps\": %.2f, \"frame_avg_ms\": %.2f, \"frame_p50_ms\": %.2f, \"frame_p95_ms\": %.2f, \"frame_p99_ms\": %.2f, \"frame_max_ms\": %.2f,\n  \"jank_frames_over_25ms\": %d, \"cpu_avg_ms\": %.2f, \"frames\": %d,\n  \"native_heap_mb\": %d, \"thermal\": \"%s\"\n}\n",
                s.fps, s.avg, s.p50, s.p95, s.p99, s.max, s.jank, s.cpuAvg, s.frames, Debug.getNativeHeapAllocatedSize() / 1048576, thermal()))
            val f = File(File(ctx.filesDir, "judgment").apply { mkdirs() }, "perf.json")
            f.writeText(b.toString())
            Log.i(TAG, "report -> " + f.absolutePath + "\n" + summaryLine(s))
            f.absolutePath
        } catch (e: Exception) { null }
    }
}

class FilamentRenderer(private val surfaceView: SurfaceView) {

    }

    private val view: View = engine.createView()

    private val resourceLoader = ResourceLoader(engine)

    private var flashEntity = 0

    private var viewH = 1
    private var destroyed = false

        view.camera = camera

        renderer.clearOptions = Renderer.ClearOptions().apply { clear = true }

        view.antiAliasing = View.AntiAliasing.FXAA
        view.ambientOcclusionOptions = View.AmbientOcclusionOptions().apply { enabled = true }
        view.bloomOptions = View.BloomOptions().apply { enabled = true; strength = Tuning.BLOOM_STRENGTH }

            .intensity(Tuning.AMBIENT_LUX)
            .build(engine)

        uiHelper.renderCallback = object : UiHelper.RendererCallback {
            override fun onNativeWindowChanged(surface: Surface) {
                swapChain?.let { engine.destroySwapChain(it) }
                swapChain = engine.createSwapChain(surface)
            }

            override fun onDetachedFromSurface() {
                swapChain?.let {
                    engine.destroySwapChain(it)
                    engine.flushAndWait()
                    swapChain = null
                }

            override fun onResized(width: Int, height: Int) {

        }
        uiHelper.attachTo(surfaceView)

    fun addGlb(bytes: ByteArray): FilamentAsset {

        buf.put(bytes)
        buf.flip()

        resourceLoader.loadResources(asset)
        asset.releaseSourceData()
        scene.addEntities(asset.entities)
        assets.add(asset)
        return asset
    }

        tm.setTransform(tm.getInstance(asset.root), m)

    fun createLights(specs: List<PointLightSpec>) {
        val em = EntityManager.get()
        pointBase = FloatArray(specs.size)
        for ((i, s) in specs.withIndex()) {
            val e = em.create()
            LightManager.Builder(LightManager.Type.POINT)
                .color(s.r, s.g, s.b)
                .intensity(s.lumens)
                .position(s.x, s.y, s.z)
                .falloff(s.falloff)
                .castShadows(false)
                .build(engine, e)
            scene.addEntity(e)
            pointEntities.add(e); lightEntities.add(e)
            pointBase[i] = s.lumens
        }
        val f = em.create()
        LightManager.Builder(LightManager.Type.FOCUSED_SPOT)
            .color(1.0f, 0.94f, 0.82f)
            .intensity(Tuning.FLASHLIGHT_LUMENS)
            .position(0f, 1.5f, 0f)
            .direction(0f, 0f, -1f)
            .falloff(Tuning.FLASHLIGHT_RANGE)
            .spotLightCone(Tuning.FLASHLIGHT_INNER, Tuning.FLASHLIGHT_OUTER)
            .castShadows(true)
            .build(engine, f)
        scene.addEntity(f)
        flashEntity = f
        lightEntities.add(f)
    }

    /** factors[i] înmulțește intensitatea de bază a becului i. */
    fun updateLights(factors: FloatArray, flashOn: Boolean, px: Float, py: Float, pz: Float, dx: Float, dy: Float, dz: Float) {
        val lm = engine.lightManager
        for (i in pointEntities.indices) {
            val inst = lm.getInstance(pointEntities[i])
            lm.setIntensity(inst, pointBase[i] * (if (i < factors.size) factors[i] else 1f))
        }
        if (flashEntity != 0) {
            val inst = lm.getInstance(flashEntity)
            lm.setIntensity(inst, if (flashOn) Tuning.FLASHLIGHT_LUMENS else 0f)
            lm.setPosition(inst, px, py, pz)
            lm.setDirection(inst, dx, dy, dz)
        }
    }

    fun setCamera(ex: Float, ey: Float, ez: Float, dx: Float, dy: Float, dz: Float) {
        camera.lookAt(
            ex.toDouble(), ey.toDouble(), ez.toDouble(),
            (ex + dx).toDouble(), (ey + dy).toDouble(), (ez + dz).toDouble(),
            0.0, 1.0, 0.0
        )
    }

    fun render(frameTimeNanos: Long) {
        if (destroyed || !uiHelper.isReadyToRender) return
        val sc = swapChain ?: return
        if (renderer.beginFrame(sc, frameTimeNanos)) {
            renderer.render(view)
            renderer.endFrame()
        }
    }

    /** Eliberează tot, în ordinea cerută de Filament. Idempotent. */
    fun destroy() {
        if (destroyed) return
        destroyed = true
        uiHelper.detach()
        val lm = engine.lightManager
        for (e in lightEntities) {
            lm.destroy(e)
            EntityManager.get().destroy(e)
        }
        lightEntities.clear()
        for (a in assets) assetLoader.destroyAsset(a)
        assets.clear()
        assetLoader.destroy()
        materialProvider.destroyMaterials()
        materialProvider.destroy()
        resourceLoader.destroy()
        indirectLight?.let { engine.destroyIndirectLight(it) }
        engine.destroyRenderer(renderer)
        engine.destroyView(view)
        engine.destroyScene(scene)
        engine.destroyCameraComponent(cameraEntity)
        EntityManager.get().destroy(cameraEntity)
        engine.destroy()
    }
}

/**
 * Salvare locală, privată aplicației: filesDir/judgment/save.json (nu necesită permisiuni, se șterge la dezinstalare).
 * Scriere atomică (fișier temporar + redenumire). Versionată pentru migrări viitoare.
 */
class SaveStore(ctx: Context) {
    private val dir = File(ctx.filesDir, "judgment").apply { mkdirs() }
    private val file = File(dir, "save.json")

    fun load(): SaveData? {
        return try {
            if (!file.exists()) return null
            val o = JSONObject(file.readText())
            if (o.optInt("v", 0) != 1) return null
            val px = o.getDouble("px").toFloat()
            val pz = o.getDouble("pz").toFloat()
            // valori absurde (fișier corupt) => ignorăm salvarea
            if (px < -3f || px > 3f || pz < -7f || pz > 2.8f) return null
            SaveData(
                o.getBoolean("doorOpen"), px, pz, o.getDouble("yaw").toFloat(),
                o.optBoolean("flashlightOn", true), o.optDouble("playSeconds", 0.0).toFloat()
            )
        } catch (e: Exception) {
            null
        }
    }

    fun save(s: SaveData) {
        try {
            val o = JSONObject()
            o.put("v", 1)
            o.put("chapter", 1)
            o.put("doorOpen", s.doorOpen)
            o.put("px", s.px.toDouble()); o.put("pz", s.pz.toDouble()); o.put("yaw", s.yaw.toDouble())
            o.put("flashlightOn", s.flashlightOn)
            o.put("playSeconds", s.playSeconds.toDouble())
            val tmp = File(dir, "save.json.tmp")
            tmp.writeText(o.toString())
            if (!tmp.renameTo(file)) { file.writeText(o.toString()); tmp.delete() }
        } catch (e: Exception) {
        }
    }
}

import java.io.ByteArrayOutputStream
import java.nio.ByteBuffer
import java.nio.ByteOrder
import java.util.Locale

/** Set de texturi PBR (PNG): culoare (sRGB), normale (liniar), metallicRoughness (G = rugozitate, B = metalic). */
class TextureSet(val name: String, val baseColorPng: ByteArray, val normalPng: ByteArray, val mrPng: ByteArray)

class GlbMaterial(
    val name: String,
    val textures: TextureSet?,
    val baseColorFactor: FloatArray = floatArrayOf(1f, 1f, 1f, 1f),
    val metallic: Float = 0f,
    val roughness: Float = 1f,
    val emissive: FloatArray? = null
)

class GlbPrimitive(val mesh: MeshBuilder, val material: Int)

/**
 * Scrie un fișier glTF binar (GLB 2.0) dintr-o listă de materiale și primitive. Fără dependențe Android:
 * se poate testa pe JVM. Texturile sunt încorporate (PNG) și deduplicate pe TextureSet.
 */
object GlbWriter {
    private const val MAGIC = 0x46546C67
    private const val CHUNK_JSON = 0x4E4F534A
    private const val CHUNK_BIN = 0x004E4942

    private class View(val offset: Int, val length: Int, val target: Int)

    private fun f(v: Float): String = String.format(Locale.US, "%.6f", v)

    fun write(materials: List<GlbMaterial>, prims: List<GlbPrimitive>, meshName: String = "mesh"): ByteArray {
        val bin = ByteArrayOutputStream()
        val views = ArrayList<View>()
        val accessors = StringBuilder()
        var accessorCount = 0

        fun align4() { while (bin.size() % 4 != 0) bin.write(0) }
        fun addView(bytes: ByteArray, target: Int): Int {
            align4()
            val off = bin.size()
            bin.write(bytes)
            views.add(View(off, bytes.size, target))
            return views.size - 1
        }
        fun addAccessor(view: Int, componentType: Int, count: Int, type: String, minMax: String?): Int {
            if (accessorCount > 0) accessors.append(",")
            accessors.append("{\"bufferView\":").append(view)
                .append(",\"componentType\":").append(componentType)
                .append(",\"count\":").append(count)
                .append(",\"type\":\"").append(type).append("\"")
            if (minMax != null) accessors.append(",").append(minMax)
            accessors.append("}")
            return accessorCount++
        }
        fun floats(list: List<Float>): ByteArray {
            val bb = ByteBuffer.allocate(list.size * 4).order(ByteOrder.LITTLE_ENDIAN)
            for (x in list) bb.putFloat(x)
            return bb.array()
        }
        fun ints(list: List<Int>): ByteArray {
            val bb = ByteBuffer.allocate(list.size * 4).order(ByteOrder.LITTLE_ENDIAN)
            for (x in list) bb.putInt(x)
            return bb.array()
        }

        // ---- geometrie ----
        val primJson = StringBuilder()
        for ((pi, pr) in prims.withIndex()) {
            val m = pr.mesh
            require(m.vertexCount > 0 && m.indices.isNotEmpty()) { "primitivă goală" }
            var minX = Float.MAX_VALUE; var minY = Float.MAX_VALUE; var minZ = Float.MAX_VALUE
            var maxX = -Float.MAX_VALUE; var maxY = -Float.MAX_VALUE; var maxZ = -Float.MAX_VALUE
            for (i in 0 until m.vertexCount) {
                val x = m.positions[i * 3]; val y = m.positions[i * 3 + 1]; val z = m.positions[i * 3 + 2]
                if (x < minX) minX = x; if (x > maxX) maxX = x
                if (y < minY) minY = y; if (y > maxY) maxY = y
                if (z < minZ) minZ = z; if (z > maxZ) maxZ = z
            }
            val minMax = "\"min\":[" + f(minX) + "," + f(minY) + "," + f(minZ) + "],\"max\":[" + f(maxX) + "," + f(maxY) + "," + f(maxZ) + "]"
            val aPos = addAccessor(addView(floats(m.positions), 34962), 5126, m.vertexCount, "VEC3", minMax)
            val aNrm = addAccessor(addView(floats(m.normals), 34962), 5126, m.vertexCount, "VEC3", null)
            val aUv = addAccessor(addView(floats(m.uvs), 34962), 5126, m.vertexCount, "VEC2", null)
            val aIdx = addAccessor(addView(ints(m.indices), 34963), 5125, m.indices.size, "SCALAR", null)
            if (pi > 0) primJson.append(",")
            primJson.append("{\"attributes\":{\"POSITION\":").append(aPos)
                .append(",\"NORMAL\":").append(aNrm)
                .append(",\"TEXCOORD_0\":").append(aUv)
                .append("},\"indices\":").append(aIdx)
                .append(",\"material\":").append(pr.material).append("}")
        }

        // ---- imagini / texturi (deduplicate pe TextureSet) ----
        val images = StringBuilder()
        val textures = StringBuilder()
        var imageCount = 0
        val setBase = HashMap<TextureSet, Int>()      // index primă textură a setului: [color, normal, mr]
        fun addImage(png: ByteArray) {
            val v = addView(png, 0)
            if (imageCount > 0) { images.append(","); textures.append(",") }
            images.append("{\"bufferView\":").append(v).append(",\"mimeType\":\"image/png\"}")
            textures.append("{\"sampler\":0,\"source\":").append(imageCount).append("}")
            imageCount++
        }
        for (mat in materials) {
            val ts = mat.textures ?: continue
            if (setBase.containsKey(ts)) continue
            setBase[ts] = imageCount
            addImage(ts.baseColorPng); addImage(ts.normalPng); addImage(ts.mrPng)
        }

        // ---- materiale ----
        val matJson = StringBuilder()
        for ((mi, mat) in materials.withIndex()) {
            if (mi > 0) matJson.append(",")
            matJson.append("{\"name\":\"").append(mat.name).append("\",\"pbrMetallicRoughness\":{")
            val b = mat.baseColorFactor
            matJson.append("\"baseColorFactor\":[").append(f(b[0])).append(",").append(f(b[1])).append(",").append(f(b[2])).append(",").append(f(b[3])).append("]")
            matJson.append(",\"metallicFactor\":").append(f(mat.metallic)).append(",\"roughnessFactor\":").append(f(mat.roughness))
            val ts = mat.textures
            if (ts != null) {
                val base = setBase[ts]!!
                matJson.append(",\"baseColorTexture\":{\"index\":").append(base).append("}")
                matJson.append(",\"metallicRoughnessTexture\":{\"index\":").append(base + 2).append("}")
            }
            matJson.append("}")
            if (ts != null) matJson.append(",\"normalTexture\":{\"index\":").append(setBase[ts]!! + 1).append(",\"scale\":1.0}")
            val e = mat.emissive
            if (e != null) matJson.append(",\"emissiveFactor\":[").append(f(e[0])).append(",").append(f(e[1])).append(",").append(f(e[2])).append("]")
            matJson.append("}")
        }

        // ---- bufferViews ----
        val viewJson = StringBuilder()
        for ((i, v) in views.withIndex()) {
            if (i > 0) viewJson.append(",")
            viewJson.append("{\"buffer\":0,\"byteOffset\":").append(v.offset).append(",\"byteLength\":").append(v.length)
            if (v.target != 0) viewJson.append(",\"target\":").append(v.target)
            viewJson.append("}")
        }
        align4()
        val binBytes = bin.toByteArray()

        val json = StringBuilder()
        json.append("{\"asset\":{\"version\":\"2.0\",\"generator\":\"HiBlue-Judgment\"},")
        json.append("\"scene\":0,\"scenes\":[{\"nodes\":[0]}],")
        json.append("\"nodes\":[{\"name\":\"").append(meshName).append("\",\"mesh\":0}],")
        json.append("\"meshes\":[{\"name\":\"").append(meshName).append("\",\"primitives\":[").append(primJson).append("]}],")

package ro.lingurar.hiblue.judgment.world

import kotlin.math.PI
import kotlin.math.cos
import kotlin.math.sin

/**
 * Geometrie procedurală pentru UN material: poziții, normale, UV și indici (triunghiuri CCW).
 * UV-urile sunt în unități de lume (metri / texScale) => textura are aceeași densitate pe orice suprafață.
 */
class MeshBuilder {
    val positions = ArrayList<Float>()
    val normals = ArrayList<Float>()
    val uvs = ArrayList<Float>()
    val indices = ArrayList<Int>()

    val vertexCount: Int get() = positions.size / 3
    val triangleCount: Int get() = indices.size / 3

    private fun vert(px: Float, py: Float, pz: Float, nx: Float, ny: Float, nz: Float, u: Float, v: Float) {
        positions.add(px); positions.add(py); positions.add(pz)
        normals.add(nx); normals.add(ny); normals.add(nz)
        uvs.add(u); uvs.add(v)
    }

    /** Cutie cu 6 fețe independente (normale ascuțite). */
    fun addBox(
        minX: Float, minY: Float, minZ: Float,
        maxX: Float, maxY: Float, maxZ: Float,
        texScale: Float
    ) {
        val mn = floatArrayOf(minX, minY, minZ)
        val mx = floatArrayOf(maxX, maxY, maxZ)
        for (a in 0..2) {
            for (s in intArrayOf(-1, 1)) {
                val u = (a + 1) % 3
                val v = (a + 2) % 3
                val c = if (s > 0) mx[a] else mn[a]
                val base = vertexCount
                val us = floatArrayOf(mn[u], mx[u], mx[u], mn[u])
                val vs = floatArrayOf(mn[v], mn[v], mx[v], mx[v])
                for (i in 0..3) {
                    val p = FloatArray(3)
                    p[a] = c; p[u] = us[i]; p[v] = vs[i]
                    val n = FloatArray(3)
                    n[a] = s.toFloat()
                    vert(p[0], p[1], p[2], n[0], n[1], n[2], us[i] / texScale, vs[i] / texScale)
                }
                if (s > 0) {
                    indices.add(base); indices.add(base + 1); indices.add(base + 2)
                    indices.add(base); indices.add(base + 2); indices.add(base + 3)
                } else {
                    indices.add(base); indices.add(base + 2); indices.add(base + 1)
                    indices.add(base); indices.add(base + 3); indices.add(base + 2)
                }
            }
        }
    }

    /** Sferă UV (pentru bec). */
    fun addSphere(cx: Float, cy: Float, cz: Float, r: Float, seg: Int, texScale: Float) {
        val base = vertexCount
        for (i in 0..seg) {
            val th = PI.toFloat() * i / seg
            for (j in 0..seg) {
                val ph = 2f * PI.toFloat() * j / seg
                val nx = sin(th) * cos(ph)
                val ny = cos(th)
                val nz = sin(th) * sin(ph)
                vert(cx + nx * r, cy + ny * r, cz + nz * r, nx, ny, nz, j.toFloat() / seg * r * 6f / texScale, i.toFloat() / seg * r * 3f / texScale)
            }
        }
        for (i in 0 until seg) {
            for (j in 0 until seg) {
                val a = base + i * (seg + 1) + j
                val b = a + seg + 1
                indices.add(a); indices.add(a + 1); indices.add(b)
                indices.add(a + 1); indices.add(b + 1); indices.add(b)
            }
        }
    }

    /** Cilindru cu axa paralelă cu X (țeavă), capete deschise (nu se văd). */
    fun addCylinderX(x0: Float, x1: Float, cy: Float, cz: Float, r: Float, seg: Int, texScale: Float) {
        val base = vertexCount
        for (j in 0..seg) {
            val ph = 2f * PI.toFloat() * j / seg
            val ny = cos(ph)
            val nz = sin(ph)
            val vv = j.toFloat() / seg * 2f * PI.toFloat() * r / texScale
            vert(x0, cy + ny * r, cz + nz * r, 0f, ny, nz, x0 / texScale, vv)
            vert(x1, cy + ny * r, cz + nz * r, 0f, ny, nz, x1 / texScale, vv)
        }
        for (j in 0 until seg) {
            val a = base + j * 2       // (x0, j)
            val b = a + 1              // (x1, j)
            val c = a + 2              // (x0, j+1)
            val d = a + 3              // (x1, j+1)
            indices.add(a); indices.add(c); indices.add(b)
            indices.add(b); indices.add(c); indices.add(d)
        }
    }
}

/** Singura parte din generarea texturilor care depinde de Android: codarea PNG. */
object PngEncoder {
    fun encode(p: Pixels): ByteArray {
        val bmp = Bitmap.createBitmap(p.argb, p.w, p.h, Bitmap.Config.ARGB_8888)
        val out = ByteArrayOutputStream(p.w * p.h)
        bmp.compress(Bitmap.CompressFormat.PNG, 100, out)
        bmp.recycle()
        return out.toByteArray()
    }
}

package ro.lingurar.hiblue.judgment.world

import kotlin.math.abs
import kotlin.math.floor
import kotlin.math.max
import kotlin.math.min
import kotlin.math.sqrt

/** Imagine RGBA 8 biți ca IntArray ARGB (aceeași ordine ca android.graphics.Bitmap.setPixels). */
class Pixels(val w: Int, val h: Int) { val argb = IntArray(w * h) }

/** Zgomot de valoare periodic (textura se repetă fără cusătură). Determinist: același seed -> aceleași texturi. */
object Noise {
    private fun hash(x: Int, y: Int, seed: Int): Float {
        var h = x * 374761393 + y * 668265263 + seed * 1274126177.toInt()
        h = (h xor (h ushr 13)) * 1274126177.toInt()
        h = h xor (h ushr 16)
        return (h and 0xFFFFFF) / 16777215f
    }
    private fun mod(a: Int, m: Int): Int = ((a % m) + m) % m
    private fun smooth(t: Float): Float = t * t * (3f - 2f * t)

    /** x,y în [0,1) ; px,py = numărul de celule pe perioadă. */
    fun value(x: Float, y: Float, px: Int, py: Int, seed: Int): Float {
        val fx = x * px
        val fy = y * py
        val ix = floor(fx).toInt()
        val iy = floor(fy).toInt()
        val tx = smooth(fx - ix)
        val ty = smooth(fy - iy)
        val a = hash(mod(ix, px), mod(iy, py), seed)
        val b = hash(mod(ix + 1, px), mod(iy, py), seed)
        val c = hash(mod(ix, px), mod(iy + 1, py), seed)
        val d = hash(mod(ix + 1, px), mod(iy + 1, py), seed)
        return (a + (b - a) * tx) + ((c + (d - c) * tx) - (a + (b - a) * tx)) * ty
    }

    fun fbm(x: Float, y: Float, px: Int, py: Int, octaves: Int, seed: Int): Float {
        var sum = 0f
        var amp = 0.5f
        var total = 0f
        var fx = px
        var fy = py
        for (o in 0 until octaves) {
            sum += amp * value(x, y, fx, fy, seed + o * 31)
            total += amp
            amp *= 0.5f
            fx *= 2; fy *= 2
        }
        return sum / total
    }
}

/** Rezultatul unei texturi procedurale: culoare + hartă de înălțime + rugozitate + metalic (toate în [0,1]). */
class TexMaps(val size: Int) {
    val color = FloatArray(size * size * 3)
    val height = FloatArray(size * size)
    val rough = FloatArray(size * size)
    val metal = FloatArray(size * size)
}

object ProcTex {
    private fun clamp01(v: Float) = max(0f, min(1f, v))
    private fun lerp(a: Float, b: Float, t: Float) = a + (b - a) * t
    private fun smoothstep(e0: Float, e1: Float, x: Float): Float {
        val t = clamp01((x - e0) / (e1 - e0)); return t * t * (3f - 2f * t)
    }
    private fun put(m: TexMaps, i: Int, r: Float, g: Float, b: Float, h: Float, ro: Float, me: Float) {
        m.color[i * 3] = clamp01(r); m.color[i * 3 + 1] = clamp01(g); m.color[i * 3 + 2] = clamp01(b)
        m.height[i] = h; m.rough[i] = clamp01(ro); m.metal[i] = clamp01(me)
    }

    /** Beton murdar: pete, fisuri, porozitate. */
    fun concrete(size: Int, seed: Int): TexMaps {
        val m = TexMaps(size)
        for (py in 0 until size) for (px in 0 until size) {
            val u = px.toFloat() / size; val v = py.toFloat() / size
            val h = Noise.fbm(u, v, 6, 6, 5, seed)
            val pores = Noise.fbm(u, v, 32, 32, 2, seed + 5)
            val stain = Noise.fbm(u, v, 3, 3, 4, seed + 11)
            val ridged = 1f - abs(2f * Noise.fbm(u, v, 4, 4, 4, seed + 23) - 1f)
            val crack = smoothstep(0.93f, 0.985f, ridged)
            val tone = lerp(0.20f, 0.42f, h) * lerp(0.62f, 1.05f, stain)
            val dark = tone * (1f - 0.55f * crack) * (0.9f + 0.1f * pores)
            val i = py * size + px
            put(m, i, dark * 1.02f, dark * 1.0f, dark * 0.94f, h * 0.6f + pores * 0.25f - crack * 0.8f, lerp(0.78f, 1.0f, h) , 0f)
        }
        return m
    }

    /** Podea cu plăci 4x4, rosturi, murdărie și pete închise. */
    fun floorTiles(size: Int, seed: Int): TexMaps {
        val m = TexMaps(size)
        val tiles = 4
        for (py in 0 until size) for (px in 0 until size) {
            val u = px.toFloat() / size; val v = py.toFloat() / size
            val tu = u * tiles; val tv = v * tiles
            val cu = floor(tu).toInt(); val cv = floor(tv).toInt()
            val fu = tu - cu; val fv = tv - cv
            val edge = min(min(fu, 1f - fu), min(fv, 1f - fv))
            val grout = 1f - smoothstep(0.015f, 0.05f, edge)
            val shade = 0.85f + 0.3f * Noise.value(((cu % tiles) + tiles) % tiles / tiles.toFloat(), ((cv % tiles) + tiles) % tiles / tiles.toFloat(), tiles, tiles, seed)
            val grime = Noise.fbm(u, v, 5, 5, 5, seed + 9)
            val wear = Noise.fbm(u, v, 24, 24, 2, seed + 17)
            val base = lerp(0.16f, 0.34f, wear) * shade * lerp(0.55f, 1.0f, grime)
            val c = base * (1f - 0.7f * grout)
            val i = py * size + px
            put(m, i, c * 1.0f, c * 1.02f, c * 0.98f, (1f - grout) * 0.8f + wear * 0.15f, lerp(0.55f, 0.95f, grime) + grout * 0.2f, 0f)
        }
        return m
    }

    /** Lemn vechi: fibre pe direcția U. */
    fun wood(size: Int, seed: Int): TexMaps {
        val m = TexMaps(size)
        for (py in 0 until size) for (px in 0 until size) {
            val u = px.toFloat() / size; val v = py.toFloat() / size
            val grain = Noise.fbm(u, v, 2, 28, 4, seed)
            val rings = Noise.fbm(u, v, 3, 10, 3, seed + 7)
            val knots = Noise.fbm(u, v, 6, 6, 2, seed + 13)
            val w = lerp(0.18f, 0.5f, grain * 0.7f + rings * 0.3f)
            val dark = 1f - 0.35f * smoothstep(0.62f, 0.8f, knots)
            val i = py * size + px
            put(m, i, w * 0.95f * dark, w * 0.62f * dark, w * 0.36f * dark, grain * 0.7f, lerp(0.55f, 0.85f, grain), 0f)
        }
        return m
    }

    /** Metal ruginit: fier închis cu pete de rugină. */
    fun rustMetal(size: Int, seed: Int): TexMaps {
        val m = TexMaps(size)
        for (py in 0 until size) for (px in 0 until size) {
            val u = px.toFloat() / size; val v = py.toFloat() / size
            val rustMask = smoothstep(0.42f, 0.68f, Noise.fbm(u, v, 4, 4, 5, seed))
            val fine = Noise.fbm(u, v, 40, 40, 2, seed + 3)
            val scratches = Noise.fbm(u, v, 2, 90, 2, seed + 19)
            val ir = lerp(0.16f, 0.26f, fine)
            val r = lerp(ir, 0.42f + 0.18f * fine, rustMask)
            val g = lerp(ir, 0.17f + 0.08f * fine, rustMask)
            val b = lerp(ir * 1.05f, 0.07f, rustMask)
            val i = py * size + px
            put(m, i, r, g, b, fine * 0.5f + rustMask * 0.5f + scratches * 0.1f, lerp(0.35f, 0.9f, rustMask), lerp(0.9f, 0.1f, rustMask))
        }
        return m
    }

    /** Hartă de normale (convenția glTF: +Y în sus) din harta de înălțime, cu înfășurare periodică. */
    fun normals(m: TexMaps, strength: Float): Pixels {
        val s = m.size
        val out = Pixels(s, s)
        fun hAt(x: Int, y: Int): Float = m.height[((y + s) % s) * s + ((x + s) % s)]
        for (y in 0 until s) for (x in 0 until s) {
            val nx = (hAt(x - 1, y) - hAt(x + 1, y)) * strength
            val ny = (hAt(x, y + 1) - hAt(x, y - 1)) * strength
            val l = sqrt(nx * nx + ny * ny + 1f)
            val r = ((nx / l) * 0.5f + 0.5f) * 255f
            val g = ((ny / l) * 0.5f + 0.5f) * 255f
            val b = ((1f / l) * 0.5f + 0.5f) * 255f
            out.argb[y * s + x] = (0xFF shl 24) or (r.toInt() shl 16) or (g.toInt() shl 8) or b.toInt()
        }
        return out
    }

    fun baseColor(m: TexMaps): Pixels {
        val s = m.size
        val out = Pixels(s, s)
        for (i in 0 until s * s) {
            val r = (clamp01(m.color[i * 3]) * 255f).toInt()
            val g = (clamp01(m.color[i * 3 + 1]) * 255f).toInt()
            val b = (clamp01(m.color[i * 3 + 2]) * 255f).toInt()
            out.argb[i] = (0xFF shl 24) or (r shl 16) or (g shl 8) or b
        }
        return out
    }

    /** glTF: G = rugozitate, B = metalic (R liber, A = 255). */
    fun metalRough(m: TexMaps): Pixels {
        val s = m.size
        val out = Pixels(s, s)
        for (i in 0 until s * s) {
            val g = (clamp01(m.rough[i]) * 255f).toInt()
            val b = (clamp01(m.metal[i]) * 255f).toInt()
            out.argb[i] = (0xFF shl 24) or (0xFF shl 16) or (g shl 8) or b
        }
        return out
    }
}

import android.content.Context

/**
 * Un joc nativ înregistrat în host.
 *
 * runtime: "kotlin" | "godot" | "unity"
 * intentFactory: construiește Intent-ul către Activity-ul jocului (declarat în AndroidManifest de autorul jocului).
 *
 * Contract de rezultat: jocul se închide cu setResult(RESULT_OK, intent) și pune în intent
 * EXTRA_SCORE (Int) și EXTRA_SECONDS (Int). Scorul NU este de încredere: este revalidat pe server.
 */
class NativeGameEntry(
    val id: String,
    val runtime: String,
    val intentFactory: (Context) -> Intent
)

object NativeGames {
    const val EXTRA_GAME_ID = "hb.game.id"
    const val EXTRA_SCORE = "hb.game.score"
    const val EXTRA_SECONDS = "hb.game.seconds"

    private val idRe = Regex("^[a-z0-9][a-z0-9_-]{1,31}$")
    private val runtimes = setOf("kotlin", "godot", "unity")
    private val entries = LinkedHashMap<String, NativeGameEntry>()

    @Synchronized
    fun register(e: NativeGameEntry) {
        require(idRe.matches(e.id)) { "id de joc invalid: " + e.id }
        require(e.runtime in runtimes) { "runtime invalid: " + e.runtime }
        entries[e.id] = e
    }

    @Synchronized
    fun get(id: String): NativeGameEntry? = entries[id]

    @Synchronized
    fun list(): List<NativeGameEntry> = entries.values.toList()

    /**
     * Aici se înregistrează jocurile native ale aplicației.
     * Fiecare joc nativ = un Activity declarat în AndroidManifest + o intrare aici + un manifest în assets/games/catalog.js.
     */
    fun registerBuiltIn() {
        register(NativeGameEntry("judgment", "kotlin") { ctx -> Intent(ctx, JudgmentActivity::class.java) })
    }
}

# THE JUDGMENT · Raport tehnic și prototip (update0.0.8)

## 1. Decizia tehnică (în limbaj simplu)
**Motor ales: Google Filament** (randare 3D realistă, „PBR”), folosit direct din Kotlin.

De ce el, nu altceva:
- Este o **bibliotecă**, nu un program cu editor: se adaugă în proiect cu o linie în Gradle și se construiește tot din cod. Asta cere regula „code-first, fără editor”.
- Se **integrează în aplicația HiBlue existentă** ca un ecran nativ (un Activity Kotlin), nu ca o aplicație separată.
- Oferă calitatea grafică căutată: materiale fizice, lumini și umbre dinamice, ocluzie ambientală, bloom, ceață, vignetă; este făcut de Google pentru Android.
- Unity și Godot sunt motoare mai complete, dar se lucrează în editor, iar proiectul lor nu se potrivește cu „orice se construiește din GitHub Actions + Kotlin fără editor”. Un motor propriu ar fi o greșeală (cerința a interzis-o).

Ce NU oferă Filament (și cum am rezolvat):
| Lipsă | Rezolvare în prototip | Ce urmează |
|---|---|---|
| Fizică | coliziune proprie (cilindru vs cutii, gravitație) — suficientă pentru interior | bibliotecă de fizică doar când apar obiecte mobile complexe |
| Sunet 3D | AudioTrack + panoramare/atenuare proprie, focus audio | OpenSL/Oboe sau Spatializer (API 32+) când se justifică |
| Animație schelet | ușa e animată prin transformări; modelele cu schelet se încarcă prin glTF (suportat de Filament) | personaje / inamici |
| Editor | nu e nevoie: nivelul e cod (`LevelSpec.kt`) | |

## 2. Limitări specifice Android
- Necesită OpenGL ES 3.0 (declarat în Manifest). Telefoanele foarte vechi nu sunt suportate.
- **Doar arm64-v8a** în build (reduce mărimea APK-ului). Emulatoarele x86 și telefoanele pe 32 de biți nu rulează jocul.
- Prima pornire compilează variantele de shadere: poate exista o mică pauză (măsurată în `startup_filament_load_ms`).
- Telefoanele se încălzesc și reduc frecvența procesorului/GPU: jocul scrie `thermal` în raport; de urmărit în teste lungi.
- Umbrele dinamice și ocluzia ambientală sunt cele mai costisitoare; sunt primele de redus pe telefoane slabe (rezoluție dinamică activată).
- Memoria: texturile sunt 512×512 / 256×256 generate la pornire; un nivel mare va cere texturi comprimate (KTX/ETC2).

## 3. Fluxul pentru asset-uri și animații
Totul este reproductibil și versionat ca **sursă**, fără fișiere binare în repo:
1. `ProcTex.kt` generează texturi PBR (culoare, normale, rugozitate/metalic) cu zgomot determinist (`SEED` fix).
2. `PngEncoder.kt` le codifică PNG (singura parte dependentă de Android).
3. `MeshBuilder.kt` creează geometria (cutii, sferă, cilindru) cu UV în metri.
4. `GlbWriter.kt` scrie un fișier **glTF binar (GLB)** în memorie; Filament îl încarcă prin `gltfio`.
5. Nivelul este definit în `LevelSpec.kt`: **aceeași listă** produce grafica și coliziunile.
6. Sunetul este sintetizat în `SoundSynth.kt` (zumzet, scârțâit, pași, click).
Asset-uri externe (modele, voci) se vor adăuga ca fișiere `.glb` / `.ogg` în `app/src/main/assets/judgment/`, cu licența notată în `docs/ASSET_LICENSES.md` (încă nu există asset-uri externe). Animațiile personajelor vor veni ca animații glTF. Compresia: texturi KTX2/ETC2 când nivelul crește.
Notă onestă: texturile și sunetele procedurale sunt de calitate „prototip”; nu sunt marcate ca finale.

## 4. Workflow de testare și build
- Build: GitHub Actions existent (`assembleDebug`) → APK ca artefact. Nu s-a modificat `build.yml`.
- Teste unitare JVM (în `app/src/test/`): fizică, ușă, geometrie, container GLB. **Nu rulează în workflow-ul actual** (care face doar `assembleDebug`).
- Pe telefon: instalează APK-ul, deschide HiBlue → Games → The Judgment.
- Măsurători: vezi secțiunea 7.

## 5. Interfața cu aplicația gazdă
- **Lansare:** HiBlue (JS) → `NativeBridge.nativeGames.launch("judgment")` → `HostBridge` → `MainActivity.launchNativeGame` → `startActivityForResult(JudgmentActivity)`. Registrul este `NativeGames.registerBuiltIn()`.
- **Intrare:** extra `hb.game.id`; opțional extra boolean `benchmark` (vezi mai jos).
- **Ieșire:** `RESULT_CANCELED` (jocul nu are încă scor). Gazda emite `nativeGame {status:"cancelled"}`; interfața web închide player-ul.
- **Lifecycle:** `onPause` oprește bucla de randare, pune audio pe pauză, salvează; `onResume` reia; `onDestroy` eliberează Filament și audio (ordinea e în `FilamentRenderer.destroy`). Activity-ul este fixat pe orizontală (`sensorLandscape`).
- **Focus audio:** cerut la start (`AUDIOFOCUS_GAIN`, `USAGE_GAME`); pe pierdere, ambientul se oprește; pe „duck”, scade volumul.
- **Permisiuni:** niciuna nouă. (Nu folosește microfon, cameră sau stocare externă.)
- **Salvare:** `filesDir/judgment/save.json` (privat, scriere atomică, versiune 1): ușa, poziția, direcția, lanterna, timpul jucat. Raportul de performanță: `filesDir/judgment/perf.json`.
- **Comunicare gazdă ↔ joc:** doar Intent-ul de intrare/ieșire. Jocul nativ nu primește tokenuri și nu are acces la Supabase în această versiune.

## 6. Ce conține prototipul
O cameră închisă 6×5×3 m (podea cu plăci, pereți de beton, tavan, masă, lăzi, pat metalic, țeavă, bec care pâlpâie) și un coridor scurt după ușă. Ușa se deschide/închide (animată, cu scârțâit și pocnet poziționale). Lanterna are umbre dinamice și ușoară inerție. Mers cu pași și balans al camerei. Salvare/reluare.

## 7. Cum se măsoară performanța
- Afișaj în joc: atinge zona de sus-centru.
- Logcat: `adb logcat -s JudgmentPerf Judgment` (la fiecare 5 s: FPS, p50/p95/p99, jank >25 ms, CPU/cadru, memorie, stare termică; la pornire: timpi de inițializare).
- Benchmark automat 30 s (camera se rotește singură, apoi scrie `perf.json`):
  `adb shell am start -n ro.lingurar.hiblue/.judgment.JudgmentActivity --ez benchmark true`
  `adb shell run-as ro.lingurar.hiblue cat files/judgment/perf.json` (funcționează pe build debug).
- Nu se măsoară timpul GPU separat (nu e expus în versiunea de Filament folosită); `p95/p99` ale timpului de cadru sunt indicatorul practic.

## 8. Stare de verificare
**Verificat (Node, oglindă a algoritmilor):** fizica jucătorului pe nivelul real (gravitație, pereți, alunecare, fără „tunelare”, ușă închisă/deschisă, 10 000 de pași aleatori fără ieșire din nivel), țintirea ușii, matricea ușii, orientarea triunghiurilor geometriei, coincidența colliderelor din `LevelSpec.kt` cu testul. Parserul de update aplică 0.0.6 → 0.0.7 → 0.0.8.
**NEVERIFICAT (necesită build GitHub Actions + telefon):** compilarea Kotlin și rezolvarea dependențelor Filament, orice cod care folosește API-ul Filament/Android, aspectul (luminozitate, expunere, texturi), FPS-ul real, sunetul, tactilul, lansarea din HiBlue, testele JUnit. Valorile din `Tuning.kt` sunt estimări de calcul.

## 9. Probleme cunoscute / predare pentru sesiunea următoare
1. Dacă build-ul pică: trimite eroarea completă din Actions. Cele mai probabile locuri: versiunea `1.51.0` Filament, nume de câmpuri în `View.*Options`, semnătura `UbershaderProvider`.

3. Hărțile de normale pot avea relieful inversat pe o axă (convenția nu a putut fi verificată vizual): se inversează semnul în `ProcTex.normals`.
4. Ușa nu are coliziune cât stă deschisă (poate intersecta jucătorul).
5. Jocul nativ nu trimite scor/progres către Supabase (nu are încă mecanică de scor).
6. Coperta din HiBlue este SVG; jocul cere orientare orizontală și rotește Activity-ul propriu, nu pe cel al aplicației.
7. Pași următori propuși (fără a schimba fundația): umbre mai fine pentru bec, texturi comprimate, un al doilea spațiu, dialog/voce, sistem de puzzle-uri.
